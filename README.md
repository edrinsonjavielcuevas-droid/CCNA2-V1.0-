# CCNA2-V1.0- : Switching, Routing, and Wireless Essentials

Welcome to the second phase of my journey toward the Cisco CCNA certification and my transition into a Security Operations Center (SOC) Analyst role. 

This repository contains my structured study notes, network diagrams, and practical labs executed within a Linux environment. I am actively documenting one module per week to build a rock-solid foundation in network infrastructure and switching technologies.

## 🎯 Objective
Mastering switching, routing, and wireless concepts is a critical stepping stone for my career in cybersecurity. A deep understanding of how data flows and how network protocols operate at a fundamental level is absolutely essential before advancing into deep traffic analysis, threat hunting, and using security tools like Wireshark, Splunk, and Metasploit.
