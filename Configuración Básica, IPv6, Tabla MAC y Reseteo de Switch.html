Cisco Lab 1.1.7 Extract

Configuración Básica, IPv6, Tabla MAC y Reseteo de Switch

[!] INFO: Esta guía contiene comandos extraídos de la práctica 1.1.7, estructurados sin repeticiones y orientados como material general de referencia para la certificación CCNA.

01. Preparación del Sistema y SDM (Soporte IPv6)

show sdm prefer
Switch#
Muestra la plantilla actual del Switch Database Manager (SDM). Verifica si el switch tiene habilitado el soporte para IPv6.
sdm prefer dual-ipv4-and-ipv6 default
Switch(config)#
Cambia la plantilla SDM para soportar direccionamiento dual (IPv4 e IPv6). Requiere reiniciar el dispositivo para aplicar los cambios.
reload
Switch#
Reinicia el switch. (Si el objetivo es restablecer a valores de fábrica, se debe responder "no" al momento de guardar la configuración).

02. Verificación de Interfaces y Sistema

show version
Switch#
Proporciona información sobre la versión de IOS, nombre de la imagen, tiempo de actividad y la dirección MAC base física del equipo.
show flash:
Switch#
Lista los archivos almacenados en la memoria flash, incluyendo la imagen del sistema operativo (archivo .bin) o el archivo vlan.dat. (Alternativa: dir flash:).
show interface f0/6
Switch#
Muestra el estado físico (up/down), métricas de velocidad, parámetros de dúplex y la dirección MAC de un puerto FastEthernet específico.
show ip interface vlan 1
Switch#
Despliega las propiedades y el estado del protocolo IP asignado a la interfaz virtual de la VLAN (SVI).

03. Configuración Global, Accesos y Contraseñas

no ip domain-lookup
Switch(config)#
Previene bloqueos del sistema impidiendo que el switch intente traducir comandos introducidos incorrectamente como resoluciones de nombres de dominio DNS.
enable secret class
Switch(config)#
Protege el acceso al modo EXEC privilegiado aplicando una contraseña fuertemente encriptada ("class" como ejemplo).
ip default-gateway 192.168.1.1
Switch(config)#
Establece la puerta de enlace predeterminada. Es un requisito fundamental para la administración remota del switch desde una subred distinta.
logging synchronous
Switch(config-line)#
Utilizado dentro de las líneas de consola o VTY, evita que los mensajes de eventos y registros del sistema interrumpan la escritura de comandos en la interfaz.

04. VLAN Administrativa, Rangos e IPv6

interface vlan 99
Switch(config)#
Ingresa a la interfaz lógica SVI asociada a la VLAN 99 para la configuración de direccionamiento IP de administración.
ipv6 address 2001:db8:acad::2/64
Switch(config-if)#
Configura una dirección IPv6 Global Unicast estática en la interfaz activa.
ipv6 address fe80::2 link-local
Switch(config-if)#
Asigna explícitamente una dirección IPv6 Link-Local (facilita la identificación estática del gateway en la red local).
interface range f0/1 - 24, g0/1 - 2
Switch(config)#
Selecciona múltiples interfaces físicas simultáneamente para aplicar configuraciones masivas en un solo paso.

05. Administración de Tabla MAC (Capa 2)

Concepto: Los switches asocian puertos físicos con direcciones MAC evaluando la dirección de origen (Source MAC) contenida en las tramas Ethernet entrantes.
show mac address-table dynamic
Switch#
Filtra y muestra exclusivamente las entradas de la tabla de direcciones MAC que el switch ha aprendido de forma automática (dinámicas).
clear mac address-table dynamic
Switch#
Limpia todas las entradas MAC dinámicas de la tabla de conmutación. Fuerza al dispositivo a reaprender las topologías de capa 2.
mac address-table static [MAC] vlan 99 interface f0/6
Switch(config)#
Fija manualmente una dirección MAC estática a un puerto y VLAN específicos, limitando qué equipo de origen puede utilizar dicha interfaz.
no mac address-table static [MAC] ...
Switch(config)#
Al anteponer el parámetro "no", se elimina la entrada de MAC estática previamente configurada.

06. Reseteo de Fábrica (Inicialización)

Advertencia: La ejecución conjunta de estos comandos purgará completamente la configuración de un switch.
delete vlan.dat
Switch#
Elimina el archivo de base de datos de VLANs alojado en la memoria Flash (necesario ya que la configuración de VLANs no reside en la NVRAM estándar).
erase startup-config
Switch#
Elimina el archivo de configuración de inicio de la NVRAM. (Posterior a la confirmación, se requiere ejecutar el comando reload).
