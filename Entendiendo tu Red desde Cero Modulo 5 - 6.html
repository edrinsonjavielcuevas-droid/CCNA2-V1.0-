Entendiendo tu Red desde Cero

Una guía para principiantes absolutos. Primero entenderemos "qué" hace cada tecnología con ejemplos de la vida real, y luego te daré "cómo" se escribe el código completo de cada equipo sin dejar nada fuera.

1. El Diccionario del Principiante (Analogías)

Antes de ver comandos extraños, vamos a entender qué estamos armando. Imagina que tu red es un edificio de oficinas gigante.

VLAN (Redes Virtuales)

Analogía: Son como los "departamentos" de una empresa. Aunque el equipo de Matemáticas y los Analistas SOC estén en el mismo edificio (switch físico), las VLANs colocan muros invisibles entre ellos para que no se mezclen los datos ni haya desorden.

Troncales (Trunks)

Analogía: Son los "ascensores" principales del edificio. Permiten que la gente (datos) de todos los departamentos (VLANs) suban y bajen por un solo tubo para ir de un piso (switch) a otro.

EtherChannel

Analogía: Imagina que tienes 2 cables de red entre dos switches. EtherChannel los "amarra" lógicamente para que funcionen como una sola autopista gigante de 2 carriles. Da más velocidad y si un cable se rompe, la red no se cae.

STP (Spanning Tree)

Analogía: Es el "policía de tránsito". En redes, si conectas switches formando un círculo, los datos dan vueltas infinitas hasta que la red explota. STP detecta estos círculos y pone un cartel de "Calle Cerrada" (bloquea un puerto) para que los datos fluyan bien. Se usa como ruta de respaldo.

DHCP

Analogía: Es la "recepcionista". Cuando conectas una PC o teléfono nuevo, el servidor DHCP le entrega automáticamente un gafete con su Dirección IP para que pueda navegar, sin que tú tengas que configurarlo a mano.

OSPF

Analogía: Es el "Waze o Google Maps" de los routers. Los routers se mandan mensajes entre sí diciéndose: "Oye, yo conozco el camino a la VLAN 10". Así todos saben la mejor ruta para enviar los paquetes.

2. ¿Qué significan estos comandos raros?

En el código verás palabras que se repiten mucho. Esto es lo que le dicen a la máquina:

  • enable y configure terminal: Es como poner la contraseña de administrador para poder editar el equipo.
  • vtp mode transparent: Le dice al switch "no aceptes configuraciones de VLAN de otros, crea las tuyas propias".
  • spanning-tree mode rapid-pvst: Enciende al "policía de tránsito" en su versión más rápida.
  • interface fa0/1: Selecciona un enchufe específico del equipo (FastEthernet 0/1) para configurarlo.
  • switchport mode access: Le dice al enchufe: "Tú solo vas a conectar a una computadora normal".
  • switchport access vlan 10: "Esa computadora que conectes, métela al grupo de Matemáticas".
  • write memory: Guarda todo lo que hiciste para que no se borre si se va la luz.

3. Las "Trampas" del Profesor (Explicadas)

¿Por qué le pusimos "spanning-tree cost 1000"?
El profesor pidió bloquear un enlace a propósito (Ruta de respaldo). En redes, STP busca el camino más "barato" (más corto). Si le decimos que el costo de ese cable es 1000 (carísimo), STP dirá: "Mejor bloqueo esta calle y no la uso a menos que la calle principal se rompa". ¡Así de simple bloqueaste la ruta!
Subinterfaces en el Router (Ej. gig0/0/0.10) - "Router on a Stick"
El router solo tiene un cable físico (gig0/0/0) conectado al switch. ¿Cómo atiende a 3 VLANs distintas? Lo "cortamos" en pedazos virtuales por software (.10, .20, .150) y a cada pedacito le decimos: "Tú atiende a la VLAN 10", usando encapsulation dot1Q 10.

🔌 Switch0 (Switch de Distribución / Triángulo)
! Entramos a modo de configuración
enable
configure terminal
hostname Switch0
vtp mode transparent
spanning-tree mode rapid-pvst

! 1. Creamos los "Departamentos" (VLANs)
vlan 10
 name MATH_DEPT
vlan 20
 name SOC_ANALYSTS
vlan 150
 name VOIP_LICEY_HQ
exit

! 2. Enchufe hacia el Router (El cable que saca los datos de la red local)
interface gig0/1
 description ENLACE PRINCIPAL HACIA ROUTER R-1
 switchport mode trunk
 exit

! 3. Agrupando cables físicos en EtherChannels
interface range fa0/1-2
 description TRONCALES FISICOS HACIA SWITCH01
 channel-group 1 mode active
 exit

interface range fa0/5-6
 description TRONCALES FISICOS HACIA SWITCH02
 channel-group 3 mode active
 exit

! 4. Configurando la Autopista (EtherChannel 1)
interface port-channel 1
 description ETHERCHANNEL 1 HACIA SWITCH01
 switchport mode trunk
 spanning-tree cost 1
 exit

! 5. La trampa del profesor: Hacer que este camino sea de respaldo bloqueado
interface port-channel 3
 description ETHERCHANNEL 3 HACIA SWITCH02 RUTA RESPALDO
 switchport mode trunk
 spanning-tree cost 1000
 end

! Guardamos los cambios

🌐 Router R-1 (El Enrutador de la red izquierda)
enable
configure terminal
hostname R-1

! Conexión directa (Punto a Punto) hacia el otro lado de la empresa
interface gig0/0/1
 description ENLACE PUNTO A PUNTO HACIA SWITCH L3
 ip address 172.16.20.1 255.255.255.252
 no shutdown
 exit

! Encendemos el cable físico hacia la red local (Switch0)
interface gig0/0/0
 description ENLACE FISICO HACIA TRIANGULO ETHERCHANNEL
 no shutdown
 exit

! Subinterfaces: Partimos el cable físico en 3 virtuales para enrutar las VLANs
interface gig0/0/0.10
 description GATEWAY MATH DEPT
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 exit
interface gig0/0/0.20
 description GATEWAY SOC ANALYSTS
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 exit
interface gig0/0/0.150
 description GATEWAY VOIP LICEY HQ
 encapsulation dot1Q 150
 ip address 192.168.150.1 255.255.255.0
 exit

! DHCP: Protegemos las IPs principales (la .1 de los routers) para que no se las den a las PCs
ip dhcp excluded-address 192.168.10.1
ip dhcp excluded-address 192.168.20.1
ip dhcp excluded-address 192.168.150.1

! DHCP: Creamos las bolsas (pools) para repartir IPs automáticas a las PCs
ip dhcp pool DHCP_MATH
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 exit
ip dhcp pool DHCP_SOC
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 exit
ip dhcp pool DHCP_VOIP_HQ
 network 192.168.150.0 255.255.255.0
 default-router 192.168.150.1
 option 150 ip 192.168.150.1
 exit

! OSPF: El GPS que le avisa a los otros equipos qué redes conocemos
router ospf 1
 network 192.168.10.0 0.0.0.255 area 0
 network 192.168.20.0 0.0.0.255 area 0
 network 192.168.150.0 0.0.0.255 area 0
 network 172.16.20.0 0.0.0.3 area 0
 end

write memory
