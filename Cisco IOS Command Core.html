Cisco IOS Command Core

Terminal de Estudio: Configuración, Seguridad y Diagnóstico de Redes

[!] INTEL: Presta atención a la columna de modo (rojo). En Cisco IOS, la jerarquía es vital. No puedes configurar una IP (Interface Config) si estás en modo privilegiado (#).

01. Navegación y Verificación

enable
Switch> (User)
Activa el Modo EXEC Privilegiado. Otorga permisos para ver configuraciones y acceder al modo global.
show running-config
Switch# (Privileged)
Muestra la configuración activa en la RAM. Ideal para ver los cambios que acabas de hacer antes de guardarlos.
show startup-config
Switch# (Privileged)
Muestra la configuración guardada en la NVRAM. Es lo que el switch cargará si se reinicia repentinamente.
show vlan brief
Switch# (Privileged)
Lista todas las VLANs creadas y muestra qué puertos físicos pertenecen a cada una.

02. Configuración Global & Seguridad Base

configure terminal
Switch#
Entra al Modo de Configuración Global. Las acciones aquí afectan al dispositivo entero.
hostname S1
Switch(config)#
Asigna un nombre al dispositivo. Fundamental para identificar equipos en la red.
no ip domain-lookup
Switch(config)#
Evita que el switch se congele intentando traducir comandos mal escritos buscando en un servidor DNS.
enable secret [pass]
Switch(config)#
Crea una contraseña fuertemente encriptada (MD5/SHA) para proteger la entrada al modo privilegiado.
service password-encryption
Switch(config)#
Encripta contraseñas que por defecto estarían en texto plano (como las de consola o VTY).
banner motd # [Msg] #
Switch(config)#
Mensaje del día. Muestra una advertencia legal antes del inicio de sesión (ej. "Acceso no autorizado prohibido").

03. Interfaces, VLANs y Direccionamiento

vlan 99
Switch(config)#
Crea la VLAN 99. Es buena práctica usar una VLAN distinta a la 1 para administración.
interface vlan 99
Switch(config)#
Entra a la Interfaz Virtual del Switch (SVI). Aquí se le asigna la IP al switch para poder administrarlo por red.
ip address [IP] [Máscara]
Switch(config-if)#
Asigna una IPv4 a la interfaz.
no shutdown
Switch(config-if)#
Enciende administrativamente el puerto o la SVI.
switchport mode access
Switch(config-if)#
[NUEVO] Fuerza al puerto a actuar solo para conexión de dispositivos finales (PCs, impresoras), no para conectar a otros switches.
switchport access vlan 99
Switch(config-if)#
Asigna el puerto seleccionado a la VLAN específica para que los dispositivos se comuniquen en esa subred.

04. Troncales, Port Security y SSH (Avanzado)

Expansión: Estos comandos no estaban en tu laboratorio inicial, pero son cruciales para exámenes como CCNA y entornos de red reales.
switchport mode trunk
Switch(config-if)#
[NUEVO] Configura el puerto como troncal. Permite el paso de múltiples VLANs a través de un solo cable (usado entre Switches o Switch-Router).
switchport port-security
Switch(config-if)#
[NUEVO] Activa la seguridad del puerto. Protege la red limitando cuántas y cuáles direcciones MAC pueden conectarse a ese puerto físico.
switchport port-security mac-address sticky
Switch(config-if)#
[NUEVO] Hace que el puerto aprenda dinámicamente la MAC de la primera PC que se conecte y la guarde en la configuración permanentemente.
crypto key generate rsa
Switch(config)#
[NUEVO] Genera llaves de encriptación. Es el paso principal para habilitar SSH (acceso remoto seguro) en lugar de usar Telnet (que es inseguro).
transport input ssh
Switch(config-line)#
[NUEVO] Se aplica en las líneas VTY. Obliga a que cualquier conexión remota use SSH y rechaza conexiones Telnet.

05. Diagnóstico de Red & Guardado

ping [IP]
Cualquier Modo #
[NUEVO] Envía paquetes ICMP para comprobar conectividad básica. (Ej. ping 192.168.1.10).
show mac address-table
Switch#
[NUEVO] Muestra qué direcciones MAC ha aprendido el switch y en qué puerto está conectada cada PC. Vital para rastrear problemas de capa 2.
show cdp neighbors
Switch#
[NUEVO] Cisco Discovery Protocol. Muestra un mapa mágico de otros dispositivos Cisco directamente conectados a este equipo.
copy running-config startup-config
Switch#
Guarda todo tu trabajo en la NVRAM. Si no ejecutas esto, al reiniciar el switch se borrará todo. (Atajo: copy run start).
